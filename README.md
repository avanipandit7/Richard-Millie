# ⌚ AURUM — Luxury Watch Showcase Website

AURUM is a premium luxury watch landing page inspired by high-end horology brands. The website combines elegant typography, immersive animations, responsive layouts, and interactive UI elements to create a sophisticated digital experience for showcasing luxury timepieces.

---

## ✨ Features :

### 🎯 Hero Section
- Full-screen luxury landing page
- Animated SVG watch illustration
- Elegant typography with premium branding
- Call-to-action buttons
- Smooth scroll indicator

### 🎨 Modern UI/UX
- Dark & Light theme toggle
- Custom animated cursor
- Luxury gold color palette
- Glassmorphism-inspired navigation
- Smooth page transitions

### 📱 Responsive Design
- Mobile-first approach
- Tablet and desktop optimization
- Responsive navigation menu
- Adaptive grids and layouts

### ⌚ Watch Collection Showcase
- Premium watch cards
